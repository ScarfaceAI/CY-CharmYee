# 承意 · CY-CharmYee 1.9.0

2026-11-17 · Windows

承意从“帮抖音创作者转文字的工具”往“在你电脑上运行的个人知识与决策伙伴”走了一步：转写稿、校对稿和知识库可以一起搜，重要决定可以记下来、到期复盘。转写新增本机识别，不用申请 Key，音频不出电脑；不过它在正式基准里明显不如豆包，所以豆包仍是默认引擎，本地识别只作可选。

## 功能与变化

- **本地识别（可选）。** 在工作区 `config.json` 设 `"asr_engine": "local"` 后，用本机的 Qwen3-ASR-0.6B 模型识别，不需要豆包凭据，音频不出电脑。模型约 1 GB，第一次需要时在后台下载，按清单校验大小和 SHA-256；预计较长的识别转到后台，可以查进度、取消和续跑。正式基准里它的错字率是豆包的 1.77 倍（盲评中 4.35 倍），人名、数字、术语也不如豆包，详见[本地识别正式基准](../verification/local-asr-benchmark.md)。
- **稿子更好核对。** 本地识别的新结果另存模型原文，数字和中英文间距作为可还原的展示层，`redisplay` 换展示方式不用重新识别；登记校对稿后学习词级纠错记忆，只提示、不自动改；每份稿子附疑点清单。数字转换和热词复听在正式基准里一处也没修好，默认关闭，需要时在配置里打开 `number_conversion`、`asr_hotwords`；中英文间距默认开启。这几项只作用于本地识别的新结果，豆包结果保持原样。
- **一条命令出稿。** `quick` 把一个链接或文件直接转成稿。各命令统一返回 `tell_user`，更新提醒、模型下载进度和获取失败后的退路都由程序写好，同一次对话最多提醒一次。
- **获取更稳。** 2026 年 8 月起抖音分享页只返回空壳，不再带作品数据，所以单条视频改为先走匿名浏览器，分享页留作后备。`selftest` 用你自己的样本链接试几种获取方式，失败过的匿名方式往后排，已登录的浏览器始终最后试；只有某条样本所有不用账号的方式都失败，才提示在抖音 App 里保存到本地、再把文件拖进来。
- **全文搜索。** `search` 一起搜机器原稿、校对稿和已开启方向的知识库页面，两个字的词也能搜到，只返回命中的片段。`kb context` 改用同一个索引。
- **决策记录与复盘。** `decide` 在知识库对应方向的 `决策/` 下记决定；到了复盘日期，在对话开头提醒（每次最多点名 3 个，其余合成一句）；复盘时追加三栏；做新决定时调出相关的旧决定和资料。
- **外部个人画像只读。** 承意不再写知识库外面的画像文件，新的回答连同来源存进库内的 `生活/个人档案/补充资料.md`。`kb profile --external` 登记或更换外部画像，`kb profile --none` 取消引用。
- **文档与规则。** 文档只留中文（`welcome --lang en` 仍可用）。首页换成新定位，数据去向和使用限制单独成页，见[数据、网络与使用限制](../limits.md)，并写清 Agent 分级：Claude Code、Codex 是一级，其余 4 个是“安装适配，社区支持”。转一条视频（含默认校对）要读的规则从约 71 KB 降到不到 20 KB。
- **修正。** 正式基准中发现，本地识别的短段偶尔带出模型内部标记 `<asr_text>`，现在出稿前会清掉。

## 升级与兼容

- 已安装承意 1.6.0 及以后可用 `update --apply` 正常更新。更新时会联网从 PyPI 安装新增的运行依赖 sherpa-onnx、numpy、pypinyin，版本固定在 `requirements.lock.txt`；安装失败会保留现场，可以再次运行。
- 默认引擎仍是豆包，凭据、配置和已有任务都不用迁移。识别模型只在开启本地识别后才下载；公开词库和 jieba 词典同样按需下载并校验，都不进安装包。
- 搜索和决策的缓存在工作区 `.local` 下，删掉会自动重建。
- 以前为外部画像排队、还没写完的个人资料写入（`@profile`），现在会因为只读而报错，不会改写外部文件。
- 首次介绍加上了全文搜索、决策记录与复盘，已安装的用户下次对话会再看到一次介绍。
- 旧 `dyb-*` 或 `douyin-brain` 品牌版本首次迁移到承意，仍须运行新安装器。详见[维护与发布指南中的已有用户升级说明](../RELEASING.md#已有用户如何升级)。

## 验证范围

- **全量测试：** 在 Python 3.12、锁定依赖的环境里跑全量测试，603 项里 602 项通过，1 项需要真实模型文件的可选测试跳过；发布检查通过。
- **本地识别正式基准（2026-11-17）：** 素材是维护者处理过的 18 条单人口播（其中 7 条有校对稿）、维护者自己的 2 条视频（共约 9.6 分钟）和 4 段静音或纯音乐；前 18 条用当时的豆包结果对照，2 条视频由维护者本人用发布前代码发起真实豆包请求，都成功出稿。本地错字率是豆包的 1.77 倍，盲评中 4.35 倍；人名、数字、术语本地对 4／24，豆包对 15／24；静音和纯音乐一个字都没出；疑点清单没有标出 20 处关键错误中的任何一处。在维护者电脑上用 CPU 3 线程，处理速度约为实时的 2.5 倍。结论是不通过，豆包保留。
- **获取：** 用 2 条真实抖音链接在隔离目录跑过 `selftest`，匿名浏览器都能取到，公开分享页和 yt-dlp 都失败；已登录的浏览器没测。
- GitHub CI、标签、源码提交和公开安装包校验以本 Release 的公开验证附录为准。

没有验证：从 1.8.0 实际升级；真实知识库里的决定与复盘、外部画像；Claude Code、Codex 等宿主里的真实对话；字幕导入剪映后的显示效果；本地识别在多人对话、长录音、带背景音乐的长片和 Windows ARM 电脑上的表现。除上述 2 条视频的豆包对照外，本轮没有其他真实豆包请求。
