# 数据、网络与使用限制

承意目前只支持 Windows。各项功能的数据去向、获取范围和使用限制如下。

## 本机保存与语音处理

- **工作数据与凭据：** 新安装默认把工作数据保存在 Windows「文档」下的 `cy-charmyee`，本机设置在 `%LOCALAPPDATA%\cy-charmyee\settings.json`。迁移沿用已登记的位置，不因改名搬走任务或凭据。凭据使用当前 Windows 用户的 DPAPI 加密，保存在工作目录。安装包不包含 Key、登录状态或历史任务。
- **网络与识别：** 下载抖音素材会访问抖音，安装依赖和本地模型时需要联网下载相应组件。当前默认使用豆包语音识别，识别时会把音频发给豆包；只有显式把 `asr_engine` 配置为 `local` 才调用本机模型，本地识别时音频不出电脑。请根据素材权限和服务条款选择处理内容。
- **知识资料和对话：** 资料保存在你电脑上的工作目录和知识库中，承意本身不上传保存或检索的知识资料。你和 Agent 的对话，包括它读到的稿子和资料，按 Agent 服务商的规则处理。

## 抖音获取范围

- **单条公开视频获取：** 先通过无登录态的无头页面获取，再尝试普通 HTTP 分享页（2026 年 8 月起抖音分享页通常取不到数据）；必要时可尝试本机已有的专用浏览器状态。单条公开视频也保留 yt-dlp 回退。常规获取在后台运行，不弹窗抢焦点，不使用 Computer Use，也不自动登录、处理验证码或使用第三方付费解析。
- **历史验证范围：** 1.3.0 本地候选曾对固定样本实测匿名获取、真实豆包识别和画面校对，但并非每条都能获取，且没有做听音核对；详见[上一轮验收](verification/v1.3.0.md)。正式版本的功能和验证范围见 [1.4.0 版本说明](releases/v1.4.0.md)。这些记录不能证明当前每条作品都能获取，也不能证明每段声音都已核对。
- **页面变化与访问限制：** 抖音页面改版或访问限制可能导致获取失效或只能拿到部分内容。失败时按实际原因报告；只有可见阻挡容器明确提示时才报告需要登录或验证，正文、标题中的相关词和普通登录按钮本身不能证明被阻挡。只有你明确要求登录、验证或界面排障时才打开可见的专用浏览器；登录和验证码由你在本机完成。
- **主页分页：** 作者主页受分页和平台返回结果影响。未能翻到末尾时会报告不完整，不能把已获取的部分说成全部作品。

## 媒体任务与结果核查

- **博主任务中的识别：** 新增的付费识别会先展示当前批次数量、已知时长和未知项，由你确认后才提交；实际单价不明时不估算费用。只分析标题或发布文案不调用识别。图文只进入分析，独立下载入口只处理视频；视觉核对取决于当前 Agent 实际的看图能力。
- **本机检查范围：** `doctor` 只做本机检查，查看依赖、凭据和模型状态，不登录抖音，也不验证豆包云端权限。安装显示 `awaiting_api` 时仍可处理已有文字；默认豆包识别须在之后完成语音配置。
- **识别可能出错：** 人名、数字和专业词尤其容易识别错。Agent 按当前可用的看图、听音工具核查，并记录实际依据；抽样帧不是 OCR，准备材料不等于已经校对。付费请求失败或结果未知时，要先核对，再按你的要求重试。

## 知识、搜索与个人资料

- **搜索范围：** 搜索转写稿、校对稿，以及已开启方向中由知识库 `index.md` 直接链接的 Markdown 页面；决策记录也在这些索引页面内。它不等于扫描电脑上的所有文件。结果提供命中片段与出处，不把整份知识资料交给 Agent。
- **个人画像：** 已有外部个人画像可登记为只读引用；新了解到的情况可以写进承意自己的知识库并注明来源，不改原画像文件。
- **决定与提醒：** 决策记录用于保存选择、依据和复盘，不替你做决定。到期提醒只会随承意参与的对话及 `kb context` 等命令输出提供，Agent 据此在对话开头提醒；承意不在后台定时运行，也不保证未加载承意或未读取提醒输出的对话会提醒。
- **专业建议：** 承意不提供理财、医疗或法律建议，只协助整理资料、记录决定和复盘。
